📖 מדריך שגיאות

❌ שגיאות נפוצות ואיך לתקן

1. גרשיים שבורים ב-onclick (הבאג הכי נפוץ)

קורה כשמייצרים HTML בתוך JS עם onclick שמכיל גרשיים. activities.js

// ❌ שגוי — גורם לשגיאת SyntaxError: ‘

2. staffData לא נשמר ב-core.js

אם staffData חסר ב-saveGame או loadGame — הצוות נאבד בכל רענון. core.js שורה ~120

// ב-saveGame — חייב להיות: staffData: window.staffData, invBuyPrice: window.invBuyPrice, // ב-loadGame — חייב להיות: window.staffData = data.staffData ?? {}; window.invBuyPrice = data.invBuyPrice ?? {};

3. invBuyPrice לא מאותחל

אם invBuyPrice לא מוגדר מראש — פועל ה-stock crash. activities.js אתחולים

// ב-activities.js — בחלק האתחולים: if (!window.invBuyPrice) window.invBuyPrice = {};

4. Firebase — adminMsgText hardcoded

אם יש שורה כזו ב-index.html — הודעת המנהל לא נטענת מ-Firebase. index.html

// ❌ הסר את השורה הזו מ-index.html: window.adminMsgText = “…”; // ✅ ב-ui.js כבר יש fbLoadConfig() שטוען מ-Firebase

5. Service Worker — גרסה ישנה

אם sw.js מצביע על CACHE_NAME ישן — המשחק לא מתעדכן. sw.js שורה 3

// ❌ ישן: const CACHE_NAME = ‘smart-money-v7.5.9’; // ✅ עדכן לגרסה הנוכחית: const CACHE_NAME = ‘smart-money-v9.0.0’;

6. XP במקום נסיון בהודעות

כמה מקומות עדיין מציגים "XP" במקום "נסיון". ui.js שורות 219, 302, 481, 540

// שנה בארבעה מקומות: ’ XP’ → ’ נסיון’ ‘XP חדש’ → ‘נסיון להוסיף’

7. Device ID גלוי למשתמש

פלייסהולדר טכני "Device ID" גלוי בפאנל ניהול. ui.js שורות 203, 387

// שנה: placeholder=“Device ID של שחקן למחיקה” → placeholder=“מזהה שחקן למחיקה” showMsg(‘הכנס Device ID’ …) → showMsg(‘הכנס מזהה שחקן’ …)
